PROMO DELIVERY V10 — CUSTOMER ACCOUNTS + ADS

Nouvo nan V10:
- Kliyan dwe kreye kont (non, telefòn, username, modpas).
- Modpas kliyan yo estoke hashé ak Werkzeug; yo pa sove an tèks klè.
- Kliyan konekte kòm Manm Promo Delivery anvan li pase kòmand.
- Chak nouvo kòmand mare ak kont kliyan an.
- Kliyan wè "Kòmand mwen yo" epi swiv Nouveau → Préparation → En route → Livré.
- Tracking pa kòd limite ak pwòp kont kliyan an.
- Admin wè kantite manm yo.
- Nouvo seksyon Piblisite/Anons sou paj kliyan an.
- Admin ka ajoute/aktive/dezaktive/efase anons ak tit, deskripsyon, imaj URL, lyen, dat kòmansman/fen.
- Tout fonksyon V9 yo konsève: pwodwi, pri, Cash/MonCash/NatCash, transaction ID, verifikasyon peman, Admin, livreur, estatistik.

DEPLOY:
1. Upload tout fichye/folder ki nan ZIP la sou GitHub repo Promo-Delivery la.
2. Commit changes.
3. Render ap redeploy otomatikman.
4. Kenbe Environment Variables ADMIN_USER, ADMIN_PASSWORD, DRIVER_*_PASSWORD, SECRET_KEY.
5. DATABASE_URL si ou itilize PostgreSQL sou Render.

Remak piblisite:
- Pou imaj/flyer, mete yon URL imaj piblik nan Admin.
- Si pa gen imaj, aplikasyon an montre yon placeholder 📣.
